# OshiPool

**応援する人の多さが報われる、ライブ投げ銭 × 二次ファンディング（Quadratic Funding）on Solana**

ライブ会場やSNSから推しに少額の投げ銭（SOL）を送り、スポンサーが用意した「マッチングプール」を二次ファンディングの式で配分します。

```
マッチング額 ∝ (Σ√cᵢ)² − Σcᵢ     （cᵢ = ファン i の投げ銭合計）
```

同じ合計額でも「1人の大口」より「大勢の小口」の方が大きく配分されるため、資金力ではなく**ファンの層の厚さ**が可視化され、報われます。

## 来場証明（ed25519署名）によるシビル対策

二次ファンディングには「1人がウォレットを大量に作れば“大勢”を装える」という弱点（シビル攻撃）があります。OshiPool では会場が入場時に来場証明を発行します。

1. 会場は ed25519 鍵ペアを持ち、公開鍵を公開する（`lib/venue.ts`）
2. 入場ゲートで、ファンのウォレットアドレスに対して `oshipool:attend:v1:<イベント>:<アドレス>` に署名する（1チケット1回）
3. ファンは投げ銭のメモにその署名を添える（`oshipool:v1:<イベント>:<推し>:<署名>`）
4. 集計時、誰でも会場の公開鍵でオンチェーンのメモを検証でき、**証明のあるファンだけがマッチング対象**になる

署名は送金元アドレスに紐づくので、他人の証明をコピーしても無効です（送金にはそのアドレス本人の署名が必要）。画面のスイッチで「証明ありのみ / 全員」を切り替えて、水増しの効き方を比較できます。

## なぜ Solana か
- 手数料が非常に安く確定も速いので、0.01 SOL 単位の投げ銭が現実的に成り立つ
- すべての投げ銭がオンチェーンに記録されるので、配分計算を誰でも検証できる
- 投げ銭は「SOL送金＋Memo（`oshipool:v1:<イベント>:<推し>`）」という1つのトランザクションで送るため、自前プログラムなしで集計できる

## 動かし方（Linux Mint / Ubuntu）

```bash
# Node.js 22 (nvm)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# ターミナルを開き直してから
nvm install 22

# アプリ
cd oshipool
npm install
npm run dev
# → http://localhost:3000 を開く
```

ウォレット側の準備:
1. ブラウザに Phantom を入れ、設定 → 開発者設定 → **Testnet Mode / Devnet** を有効にする
2. https://faucet.solana.com で自分のアドレスに devnet SOL をもらう
3. 画面右上の「Select Wallet」から接続し、推しのカードにあるボタンで投げ銭する

### デモ用：大勢のファンをシミュレーションする

```bash
npm run seed -- --dry   # 計画だけ表示
npm run seed            # 初回は資金係ウォレットを作成 → そのアドレスに devnet SOL を送って再実行
npm run seed -- --attendees   # 来場証明つきの「本物の来場者」の投げ銭を追加
npm run pass -- <アドレス>     # 入場ゲート役：そのアドレスに来場証明を発行（初回は会場の鍵を作成）
```

直接の合計が同じ0.1 SOLでも「1人 / 5人 / 20人」で配分がどう変わるかを、devnet上の実トランザクションで再現します。
1人が大量のウォレットを作って投げ銭するこのスクリプトは、二次ファンディングに対する**シビル攻撃**の実演でもあります（対策は上の「来場証明」。`--attendees` と画面のスイッチで比較できます）。

> 公開RPCが混んでいて履歴が読めない場合は、Helius などの無料RPCのURLを `.env.local` に `NEXT_PUBLIC_RPC_URL=...` として設定してください。

## 構成
| ファイル | 役割 |
|---|---|
| `lib/config.ts` | イベント名・推し・受け取りアドレス・プール額 |
| `lib/tips.ts` | 投げ銭トランザクションの作成と、オンチェーン履歴の読み取り・集計 |
| `lib/pass.ts` | 来場証明の発行・検証（ed25519） |
| `lib/venue.ts` | 会場の公開鍵 |
| `scripts/pass.mts` | 入場ゲート役：来場証明を発行 |
| `lib/qf.ts` | 二次ファンディングの計算（プール超過時は按分） |
| `scripts/seed.mts` | デモ用：多数のファンからの投げ銭を devnet で再現 |
| `components/Simulator.tsx` | 「大口1人 vs 小口大勢」を比べる計算機 |
| `app/page.tsx` | メイン画面 |
